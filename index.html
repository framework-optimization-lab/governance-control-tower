Governance you can run, not just describe.

Most AI governance is a document. This is the same policy expressed as code you can execute: ask a question, watch it get grounded or refused, then watch a deterministic gate issue a verdict and route it to a human. Every step leaves evidence.

This edition is a single HTML file — no backend, no build step, no external services, no model in the loop. Every behavior on every page is deterministic code running in your browser. Open it from a file share or host it as one static page.

What this is assembled from

Two working repositories, joined into a single control surface.

  • governed-playbook-assistant — governance on the way in: retrieval, citation binding and refusal thresholds.
  • ai-decision-governance-gate — governance on the way out: seven deterministic controls producing PASS / REVIEW / BLOCK.
  • framework-optimization-lab — the framing: controls that are cheap to run and hard to argue with.

Governed assistant

How it works

The split matters more than the stack: a drafting layer proposes prose, and deterministic code decides. Every verdict in this demo is reproducible without a model in the loop — and in this self-contained build, there is literally no model in the loop.

What the drafting layer does

  • Composes prose from retrieved passages only.
  • In the hosted edition this is a language model under instruction; here it is extractive code.
  • It never assigns a verdict, tier, citation or risk level — in either edition.

What deterministic code does

  • Ranks passages with BM25 and computes the relevance score.
  • Refuses below the threshold before any drafting happens.
  • Assigns citations, tiers, and the seven-control verdict.

Control map

Honest limits

  • The playbook, evidence registry and figures are synthetic demonstration data.
  • Retrieval is keyword-based, not semantic — chosen so refusals are explainable by a number.
  • This build has no model: answers are assembled extractively from the retrieved passages, and the "ungoverned" baseline is a labeled simulation of what an unconstrained assistant does.
  • Records are stored in this browser only; there is no identity or access model here.
  • Seven controls are a demonstrable core, not a complete assurance framework.
